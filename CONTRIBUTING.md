# 🤝 Contribuer au projet – Fer à souder DIY tige de panini

Merci de l’intérêt que vous portez à ce projet !  
Ce document explique comment vous pouvez aider à l’améliorer, signaler des problèmes ou proposer des modifications.

---

## 🎯 Principes généraux

- Ce projet est **open source** (licence CC BY-NC 4.0)
- Il est basé sur une **expérience réelle** (matériel accessible, mesures vérifiées)
- Toute contribution doit rester dans l’esprit **DIY, pédagogique et non commercial**

---

## 🐞 Signaler un problème

Si vous rencontrez une difficulté en reproduisant ce fer à souder :

1. **Vérifiez d’abord la FAQ** (`FAQ.md`)
2. **Ouvrez une "Issue"** sur GitHub
3. Décrivez :
   - Votre matériel exact (alimentation, tige, étain)
   - Ce qui ne fonctionne pas
   - Vos mesures (tension, courant si disponibles)
   - Une photo ou schéma si possible

> Merci de rester précis et courtois.

---

## 💡 Proposer une amélioration

Vous avez une idée pour améliorer le projet ?

- **Ajout de variante** (ex : autre alimentation, autre forme de panne)
- **Correction d’erreur** (formule, schéma, faute)
- **Nouvelle section** (ex : test avec thermocouple, adaptation pour sans plomb)

👉 Ouvrez une **Issue** ou une **Pull Request** en expliquant l’intérêt de la modification.

---

## 📝 Règles pour les Pull Requests

Si vous souhaitez modifier directement les fichiers :

1. **Forkez** le dépôt
2. Créez une branche (`git checkout -b amelioration-xxx`)
3. Faites vos modifications
4. Vérifiez que la mise en forme Markdown reste propre
5. Soumettez une **Pull Request** avec une description claire

### Exemples de contributions utiles :
- Ajout de photos ou schémas
- Traduction dans une autre langue
- Retour d’expérience avec d’autres composants
- Schéma de câblage plus détaillé

---

## 🛠️ Contributions non souhaitées

- Contenu commercial ou promotionnel
- Modification de la licence
- Suppression des crédits d’auteur
- Ajout d’instructions dangereuses non vérifiées

---

## 📧 Contact

Pour toute question non liée à une issue :

- Passez par le système d’issues GitHub
- Ou laissez un commentaire sur le dépôt

---

## 🙏 Remerciements

Chaque contribution, même petite, aide d’autres bricoleurs.  
Merci de partager vos améliorations !
